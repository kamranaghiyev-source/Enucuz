BazarPro — готовый сайт-посредник (каталог товаров + услуги + сравнение)

1) Настройка:
   - Открой data/config.json
   - Поменяй whatsapp на свой номер
   - В payment_links вставь реальные ссылки на оплату (Payriff/Portmanat)
2) Запуск:
   - Открой https://app.netlify.com/drop
   - Перетащи ПАПКУ сайта (где лежит index.html)

Данные:
- data/products.json
- data/services.json
- data/compare.json


Домен:
- Чтобы никто не занял имя Enucuz.az, зарегистрируй домен enucuz.az у регистратора доменов .az.
- После регистрации подключи домен в Netlify (Domain settings).
